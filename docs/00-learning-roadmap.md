# Spring Boot Learning Roadmap

Follow this sequence. Finish the practical task in each stage before moving forward.

| Stage | Topic | Practical outcome |
|---|---|---|
| 1 | Spring Core | Build a notification service using DI and qualifiers |
| 2 | Spring Boot Basics | Configure profiles and typed properties |
| 3 | Spring MVC & REST | Build validated CRUD APIs |
| 4 | Data JPA & Hibernate | Persist entities and solve N+1 queries |
| 5 | Transactions | Implement rollback and propagation examples |
| 6 | Spring Security | Secure APIs with roles and JWT |
| 7 | Testing | Unit, slice and integration tests |
| 8 | Redis | Add caching and cache invalidation |
| 9 | WebFlux | Build a reactive endpoint and compose publishers |
| 10 | Messaging | Publish/consume events and handle retries |
| 11 | Microservices | Add discovery, gateway and central configuration |
| 12 | Distributed Systems | Practise Saga, outbox, idempotency and resilience |
| 13 | Observability | Add metrics, logs and distributed tracing |
| 14 | DevOps | Containerize and automate a build pipeline |

## Weekly execution plan

- [ ] Week 1: Spring Core and Boot fundamentals
- [ ] Week 2: REST APIs, validation and exception handling
- [ ] Week 3: JPA, SQL and transactions
- [ ] Week 4: Security and testing
- [ ] Week 5: Redis, WebFlux and messaging
- [ ] Week 6: Microservices and distributed patterns
- [ ] Week 7: Observability and Docker
- [ ] Week 8: Complete one capstone project

The schedule is a suggested pace, not a deadline. Spend more time on a topic when you cannot explain or test it independently.
