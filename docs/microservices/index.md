## Learning objective

Understand the problem this technology solves, implement a small working example, and verify its behavior with tests.

## Practical exercise

Run two services behind a gateway. Add discovery and central configuration, then test a service failure.

## Work through this module

1. Open the [module source README](https://github.com/YOUR_GITHUB_USERNAME/springboot-practical-learning/blob/main/spring-microservices/README.md).
2. Run the starter code using the root Maven project.
3. Complete the exercise and add tests.
4. Record what you learned and commit the changes.
