# Interview Preparation

Prepare for Java Backend Developer interviews with structured notes,
topic-wise questions, detailed answers and practical examples.

## Topics

| Category | Topics |
|---|---|
| Java | Core Java, OOPS, Collections, Exceptions, Multithreading, Java 8 |
| Spring | Spring Core, Spring Boot, MVC, Data JPA, Security |
| Microservices | Architecture, Communication, Saga, Resilience4j |
| Database | SQL, Indexing, Joins, Transactions |
| System Design | HLD, LLD, Design Patterns |
| Coding | Arrays, Strings, Linked Lists, Trees |
| Projects | Real-world project and resume-based questions |

## How to Prepare

1. Read `concept.md` to understand the topic.
2. Open `question.md` and try answering without help.
3. Use `answer.md` to check your answers.
4. Practise the coding examples where applicable.
