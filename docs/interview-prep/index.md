# Interview Preparation

Topic-wise preparation for Java Backend Developer interviews.

## How to use this section

1. Read `concept.md` to understand the topic.
2. Attempt every question in `question.md` without looking at answers.
3. Review `answer.md` and improve your explanation.
4. Practise coding examples and architecture diagrams.
5. Revisit weak questions during revision.

## Recommended study cycle

- **Learn:** Read the concept notes and summarize in your own words.
- **Recall:** Answer questions without opening the answer file.
- **Explain:** Speak the answer as if you are in an interview.
- **Apply:** Write code or connect the topic to a real application.
- **Revise:** Track weak topics and repeat them later.
