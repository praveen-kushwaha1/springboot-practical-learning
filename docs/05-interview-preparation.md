# Interview Preparation

Use these prompts after implementing the corresponding topic.

## Spring Core and Boot
- What problem does IoC solve?
- `@Component` vs `@Bean`?
- `@Primary` vs `@Qualifier`?
- How does Spring Boot auto-configuration work?
- What are bean scopes and lifecycle callbacks?

## REST and persistence
- PUT vs PATCH?
- How do validation and `@ControllerAdvice` work?
- Lazy vs eager loading?
- What is the N+1 query problem?
- What are transaction propagation and isolation?

## Security and distributed systems
- Authentication vs authorization?
- JWT validation and token expiry?
- How do retries cause duplicate side effects?
- What is idempotency?
- Saga choreography vs orchestration?
- What problem does the transactional outbox solve?

## Testing and operations
- Unit vs slice vs integration test?
- What does Testcontainers solve?
- Liveness vs readiness?
- Metrics vs logs vs traces?
- How would you investigate high API latency?

For every answer, prepare: definition, problem solved, implementation, trade-off, and a real example from your project.
