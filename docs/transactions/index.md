## Learning objective

Understand the problem this technology solves, implement a small working example, and verify its behavior with tests.

## Practical exercise

Create a transfer use case that debits one account and credits another atomically. Prove rollback with a failing test.

## Work through this module

1. Open the [module source README](https://github.com/YOUR_GITHUB_USERNAME/springboot-practical-learning/blob/main/spring-transactions/README.md).

3. Complete the exercise and add tests.
4. Record what you learned and commit the changes.
